 Deployment

GitHub Pages can automatically deploy the website from this repository.

To configure it:

Open the repository on GitHub.
Go to Settings → Pages.
Select the appropriate branch as the deployment source.
Save the configuration.
GitHub will publish the site through GitHub Pages.
